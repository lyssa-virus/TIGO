# Firmware do Robô TIGO (Arduino)

Esta pasta armazena os sketches do Arduino (firmware) para controle dos motores Moebius, leitura de encoders e comunicação serial/ROS.

## Estrutura recomendada
- Coloque os arquivos `.ino` e bibliotecas específicas aqui.
- Exemplo: `firmware/tigo_arduino/tigo_arduino.ino`
